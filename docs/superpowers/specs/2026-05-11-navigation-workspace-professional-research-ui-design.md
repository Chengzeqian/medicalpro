# 手术导航工作区专业科研界面优化设计

**日期：** 2026-05-11
**范围：** `medicalpro` 手术导航工作区五阶段界面：准备、规划、配准、导航、评估
**设计方向：** 深色科研工作站

## 1. 背景

当前手术导航工作区已经完成病例工作包、五阶段流程、工作区快照、单 3D 数字孪生、运行态协调、导航准入、可信度评估和病例级评估摘要等真实链路。

页面已经能表达主流程，但界面气质仍偏旧式暗色软件：

- 视觉上仍保留紫红高亮和旧按钮面板气质，不够像医疗导航科研工作站。
- 准备、规划、配准、评估页的信息组织偏功能堆叠，真实能力没有被专业地呈现。
- 导航页已经切到单 3D 数字孪生，但状态指标和主视图之间的关系还可以更清晰。
- 五阶段页面之间的视觉语言不够统一，用户需要自己理解哪些信息是病例证据、哪些是运行质控、哪些是操作入口。

本轮不新增算法，不改变病例工作包、配准、追踪、数字孪生和评估的底层能力，只优化界面结构、信息层级、控件样式和专业科研感。

## 2. 目标

1. 采用统一的深色科研工作站视觉系统。
2. 五阶段页面都显示系统已实现的真实功能，不引入占位入口。
3. 中间主工作区突出当前阶段的核心证据或核心视图。
4. 右侧运行状态栏持续显示病例、追踪器、配准误差、导航准入、可信度、探针标定和当前精度。
5. 准备、规划、配准、导航、评估都能一眼看出当前病例链路是否可继续推进。
6. 界面适合论文展示、毕业答辩和科研演示。

## 3. 非目标

- 不重写底层算法。
- 不新增硬件 SDK 深度联调。
- 不恢复旧四视图作为导航主界面。
- 不恢复旧分割、旧手动导模、旧 2D-3D 占位入口。
- 不引入新的第三方 UI 依赖。
- 不大范围重做主窗口、Dashboard 或管理页。

## 4. 视觉系统

### 4.1 色彩

采用低饱和医疗仪器风格：

- 页面背景：墨黑、深蓝灰。
- 面板背景：深灰蓝。
- 主强调色：蓝绿色，用于当前阶段、已就绪、实时导航和可信状态。
- 预警色：琥珀色，用于阻塞、待完成、需确认。
- 危险色：低饱和红色，用于追踪断开、配准失败、不可导航。
- 文本：高对比浅灰，次级信息使用蓝灰。

替换现有大面积紫红高亮，让界面更像科研仪器控制台。

### 4.2 布局

保留当前三栏结构：

- 左侧：五阶段流程轨。
- 中间：阶段主工作区。
- 右侧：运行状态和质控指标。

优化原则：

- 左侧流程轨显示阶段编号、阶段名和简短状态。
- 中间工作区优先给 3D/表格/摘要证据，不堆叠不相关按钮。
- 右侧状态栏采用密集但清晰的指标卡。
- 控件圆角控制在 6-8px，避免过度卡片化。
- 字体最小 14px，指标值可以更大。

### 4.3 文案

界面文案使用真实系统概念：

- 病例工作包
- 骨 STL
- 器械 STL
- geometry
- marker
- 标定
- 分骨配准
- 融合导航空间
- 单 3D 数字孪生
- 导航准入
- 可信度评分
- tracking latency / jitter / visible frame ratio

避免空泛文案和“功能将在此实现”类占位提示。

## 5. 五阶段设计

### 5.1 准备页

定位：病例资产确认和导航器械准备页。

页面应展示：

- 当前病例工作包摘要。
- 已绑定器械列表。
- 每个器械的 STL、geometry、marker 状态。
- 当前活动器械。
- 探针标定状态、采样进度、精度。
- 阻塞原因。

界面形态：

- 中间区域从普通器械卡片升级为资产矩阵。
- 每张器械卡显示器械名、模型绑定、geometry 绑定、marker、标定状态。
- 缺失项使用琥珀状态，不使用醒目的错误红色，除非会直接阻断导航。

允许动作：

- 刷新病例资产。
- 选择当前活动器械。
- 开始标定、采集标定点、完成标定、取消标定。

明确不展示：

- 页面内导入器械。
- 页面内导入骨模型。
- 临时写入 geometry。

### 5.2 规划页

定位：只读规划证据页。

页面应展示：

- 目标骨。
- 目标区域。
- 解剖约束区。
- 推荐配准点顺序。
- 已绑定骨模型列表。
- DICOM 是否存在和影像摘要。

界面形态：

- 左侧或中间为只读 3D/影像查看区。
- 右侧为规划摘要和病例资产证据。
- 使用“规划证据”“目标区域”“推荐采点顺序”等科研表达。

允许动作：

- 加载或查看病例已绑定 DICOM。
- 刷新规划摘要。
- 确认当前规划摘要。

明确不展示：

- 自动分割主按钮。
- 导出 STL 主按钮。
- 选择模型、加载模型、显示模型等旧导模入口。

### 5.3 配准页

定位：采点、分骨配准和融合空间确认页。

页面应展示：

- 配准 VTK 视图。
- 当前采点表。
- 当前活动骨。
- 点数、FRE、target TRE、覆盖评分。
- 分骨配准结果。
- 融合导航空间状态。
- 阻塞原因。

界面形态：

- 主视图保留配准 VTK。
- 点表和采点操作靠近主视图，减少右侧面板堆叠。
- 右侧摘要突出“采点进度”“配准结果”“融合空间”。
- 计算结果用指标块显示，不只是一行误差文本。

允许动作：

- 采集点。
- 删除选中点。
- 清空点。
- 计算配准。

明确不展示：

- 2D-3D 占位入口。
- 与当前主链路无关的额外配准模式按钮。

### 5.4 导航页

定位：单 3D 数字孪生导航页。

页面应展示：

- 单一 3D 虚拟空间。
- 骨 STL。
- 当前器械 STL。
- 实时位姿。
- 追踪可见状态。
- 配准状态。
- 标定状态。
- 导航准入。
- 可信度评分。
- 当前误差和位姿摘要。

界面形态：

- 3D 视图占据中间区域最大面积。
- 视图内可显示轻量 HUD：骨模型就绪、器械可见、FRE、准入状态。
- 右侧状态栏显示运行质控，不和主 3D 视图争抢层级。
- 开始、暂停、重置视图作为清晰操作组。

允许动作：

- 连接追踪器。
- 断开追踪器。
- 开始导航。
- 暂停导航。
- 重置视图。

明确不展示：

- Axial / Sagittal / Coronal / 3D Volume 四视图作为导航主界面。
- 导航页内旧模型加载主路径。

### 5.5 评估页

定位：病例级评估报告页。

页面应展示：

- 配准误差。
- 分骨质量摘要。
- tracking latency。
- tracking jitter。
- visible frame ratio。
- 导航过程摘要。
- 报告导出状态。
- CSV / report 导出入口。

界面形态：

- 使用科研报告式指标布局。
- 顶部为病例级结论。
- 中部为指标矩阵。
- 底部为导出状态和明细摘要。

允许动作：

- 导出评估报告。
- 查看摘要明细。

明确不展示：

- 空白占位提示。
- 非评估性质的运行态交互。

## 6. 技术设计

### 6.1 修改范围

优先修改：

- `UI/NewPages/NavigationPage.cpp`
- `UI/NewPages/NavigationPage.h`
- `UI/Forms/NavigationPage.ui`
- `UI/NewPages/Navigation/navigation_workspace_ui_binder.cpp`
- `UI/NewPages/Navigation/navigation_workspace_ui_binder.h`

必要时补充测试：

- `tests/unit/AnkleNavigationWorkflowContractTest.cpp`
- `tests/unit/NavigationWorkspaceApplicationServiceTest.cpp`
- `tests/unit/NavigationEvaluationSummaryFormatterTest.cpp`

### 6.2 实现策略

1. 抽出导航工作区 QSS 到页面代码中的统一样式函数，覆盖动态创建控件和 `.ui` 旧样式。
2. 增强 `createNavigationStatusCard`，支持指标标题、主值、状态 tone 和次级说明。
3. 增强左侧流程轨按钮，加入阶段编号和状态属性。
4. 给准备、规划、配准、评估创建统一的科研面板辅助函数。
5. 保留 `NavigationWorkspaceUiBinder` 作为真实状态写入入口，不在 UI 层伪造业务状态。
6. 只通过现有 snapshot、runtime、controller 数据刷新界面。

### 6.3 风险控制

- 不改底层服务接口，降低联调风险。
- 不删除旧底层代码，只退出主界面暴露。
- 样式修改先集中在导航页，避免影响全局页面。
- 保持现有工作区快照和契约测试通过。

## 7. 验收标准

### 7.1 整体

- 页面整体不再使用紫红作为主强调色。
- 五阶段界面视觉统一。
- 左侧流程轨、中间主工作区、右侧状态栏层级清晰。
- 所有文字不小于 14px。
- 不出现明显占位功能文案。

### 7.2 准备页

- 能看到病例工作包绑定的器械、geometry、marker、标定状态。
- 缺失项和阻塞原因清晰显示。
- 不出现页面内导入器械或导入骨模型主入口。

### 7.3 规划页

- 能看到目标骨、目标区域、约束区、推荐采点顺序。
- 能看到已绑定模型/DICOM 只读信息。
- 不出现旧分割或旧导模主入口。

### 7.4 配准页

- 能看到采点表、配准误差、分骨结果和融合导航空间状态。
- 采点、删点、清点、计算动作清晰。
- 不出现 2D-3D 占位入口。

### 7.5 导航页

- 主区域为单 3D 数字孪生。
- 运行状态能表达骨 STL、器械 STL、实时位姿、追踪、准入、可信度和误差。
- 追踪丢失时界面状态明确。

### 7.6 评估页

- 能看到病例级评估摘要和关键指标。
- 导出入口明确。
- 不再是空白占位页。

## 8. 实施顺序

1. 统一导航页科研工作站样式。
2. 优化左侧流程轨和右侧状态栏。
3. 优化准备页资产矩阵。
4. 优化规划页只读证据面板。
5. 优化配准页采点和结果面板。
6. 优化导航页 3D 主视图和 HUD。
7. 优化评估页病例级报告面板。
8. 运行导航工作区相关测试和主程序构建。

## 9. 成功判定

本轮成功的标志是：用户进入手术导航工作区后，五个阶段都像同一套医疗导航科研系统的一部分；页面直接展示病例工作包、规划、配准、导航和评估的真实状态，视觉上能够支撑论文展示和现场演示，而不是只像功能按钮集合。
