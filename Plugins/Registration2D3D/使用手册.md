## 🎯 系统简介

2D-3D配准系统是一套先进的医学图像配准解决方案，用于将术前CT 3D图像与术中X光2D图像进行精确对齐。该系统主要应用于骨科手术导航，帮助医生在手术过程中准确定位和操作。

### 核心技术
- **CMA-ES优化算法**：自适应协方差矩阵进化策略
- **GPU加速DRR生成**：快速数字重建放射影像
- **双视角配准**：支持AP（正位）和LAT（侧位）联合配准
- **实时进度反馈**：多阶段配准进度显示

## 📝 操作流程

### 步骤1：准备数据

**所需数据文件：**
1. **CT图像数据**
   - 格式：DICOM系列、NIFTI (.nii/.nii.gz)、MetaImage (.mha/.mhd)
   - 要求：完整的3D体数据，包含目标解剖结构
   - 推荐：层厚 ≤ 1mm，覆盖完整手术区域

2. **AP视角X光图像**
   - 格式：DICOM、PNG、JPG、BMP
   - 要求：正位拍摄，显示清晰的骨骼结构
   - 推荐：分辨率 ≥ 1024×1024

3. **LAT视角X光图像**
   - 格式：DICOM、PNG、JPG、BMP
   - 要求：侧位拍摄，与AP视角正交
   - 推荐：分辨率 ≥ 1024×1024

### 步骤2：加载图像数据

1. **加载CT图像**
   ```
   点击 [加载CT图像] → 选择CT数据文件或DICOM目录 → 确认
   ```
   - 系统会自动读取CT数据并生成3D模型
   - CT视图将显示3D重建预览

2. **加载X光图像**
   ```
   点击 [加载AP视图] → 选择正位X光图像 → 确认
   点击 [加载LAT视图] → 选择侧位X光图像 → 确认
   ```
   - AP视图和LAT视图将分别显示对应的X光图像

### 步骤3：设置配准参数

#### 基本参数

| 参数名称 | 默认值 | 推荐范围 | 说明 |
|---------|--------|---------|------|
| **优化算法** | CMA-ES | - | 进化策略优化算法 |
| **最大迭代次数** | 500 | 300-1000 | 越大越精确但耗时更长 |
| **初始步长** | 10.0 | 5.0-20.0 | 搜索的初始步长大小 |
| **相似度阈值** | 0.85 | 0.80-0.95 | 配准收敛的相似度目标 |
| **DRR生成方法** | GPU-Accelerated | - | 推荐使用GPU加速 |

#### 参数调整建议

**快速配准（适合初步测试）**
```
最大迭代次数: 300
初始步长: 15.0
相似度阈值: 0.80
```

**标准配准（推荐日常使用）**
```
最大迭代次数: 500
初始步长: 10.0
相似度阈值: 0.85
```

**高精度配准（适合复杂病例）**
```
最大迭代次数: 1000
初始步长: 5.0
相似度阈值: 0.90
```

### 步骤4：预览DRR（可选）

在开始配准前，可以生成DRR预览来验证数据质量：

1. 点击 **[生成DRR预览]** 按钮
2. 系统会基于当前参数生成DRR图像
3. 在配准结果视图中查看DRR与X光的初始对比
4. 如果初始位置偏差过大，可以调整初始变换参数

### 步骤5：开始配准

1. 确认所有数据和参数设置正确
2. 点击 **[开始配准]** 按钮
3. 系统开始配准计算，界面显示：
   - **进度条**：显示总体配准进度（0-100%）
   - **当前阶段**：显示配准当前所处阶段
   - **日志输出**：实时显示配准过程信息

#### 配准阶段说明

配准过程分为多个阶段，每个阶段有不同的优化目标：

| 阶段 | 进度范围 | 说明 | 预计耗时 |
|-----|---------|------|---------|
| **初始化** | 0-5% | 加载数据、初始化算法 | 5-10秒 |
| **粗配准** | 5-30% | 大范围搜索最优位置 | 30-60秒 |
| **精配准** | 30-80% | 细化配准参数 | 1-3分钟 |
| **优化收敛** | 80-100% | 最终优化和验证 | 30-60秒 |

### 步骤6：查看配准结果

配准完成后，系统会显示详细的结果信息：

#### 配准结果表格

| 参数 | 说明 |
|-----|------|
| **成功** | 是否成功完成配准 |
| **度量值** | 最终相似度分数（越高越好） |
| **迭代次数** | 实际执行的迭代次数 |
| **执行时间** | 总配准耗时（秒） |
| **AP平移** | X/Y/Z方向平移量（mm） |
| **AP旋转** | 绕X/Y/Z轴旋转角度（度） |
| **状态** | 配准状态描述 |

#### 视觉验证

在 **配准结果视图** 中：
- 查看DRR与X光图像的叠加效果
- 验证骨骼轮廓是否对齐
- 检查关键解剖标志点的匹配程度

### 步骤7：保存配准结果

1. 确认配准结果满意
2. 点击 **[保存结果]** 按钮
3. 选择保存位置和文件名
4. 系统会保存：
   - 配准变换矩阵
   - 配准参数和统计信息
   - DRR叠加图像

## 🔢 参数说明

### 优化算法参数

#### CMA-ES（协方差矩阵自适应进化策略）

**算法特点：**
- 自适应步长调整
- 适合高维非线性优化
- 对初始值不敏感
- 收敛稳定

**参数调优：**

**最大迭代次数 (maxIterations)**
- **作用**：控制优化搜索的最大步数
- **影响**：
  - 过小：可能无法达到最优解，配准精度降低
  - 过大：增加计算时间，但不一定提高精度
- **选择建议**：
  - 简单病例：300-500次
  - 复杂病例：700-1000次
  - 观察日志中的收敛情况，如果提前收敛可以减少迭代次数

**初始步长 (initialStepSize)**
- **作用**：控制参数搜索的初始范围
- **影响**：
  - 过大：搜索不稳定，可能错过最优解
  - 过小：搜索速度慢，容易陷入局部最优
- **选择建议**：
  - 初始位姿较准：5.0-8.0
  - 初始位姿未知：10.0-15.0
  - 大幅度调整需求：15.0-20.0

**相似度阈值 (similarityThreshold)**
- **作用**：配准收敛的目标相似度
- **影响**：
  - 过高：难以达到，可能导致配准失败
  - 过低：配准精度不足
- **选择建议**：
  - 图像质量好：0.90-0.95
  - 图像质量一般：0.85-0.90
  - 图像质量差：0.80-0.85

### DRR生成参数

**GPU加速 vs CPU计算**

| 特性 | GPU加速 | CPU计算 |
|-----|--------|---------|
| **速度** | 快（10-100倍） | 慢 |
| **精度** | 高 | 高 |
| **要求** | 需要CUDA支持的显卡 | 无特殊要求 |
| **推荐** | ✅ 强烈推荐 | 仅用于测试 |

## ❓ 常见问题

### Q1: 配准一直失败怎么办？

**可能原因和解决方案：**

1. **图像质量问题**
   - ✅ 检查X光图像是否清晰
   - ✅ 确认CT数据完整性
   - ✅ 尝试提高图像对比度

2. **初始位姿偏差过大**
   - ✅ 生成DRR预览查看初始对齐情况
   - ✅ 手动调整初始变换参数
   - ✅ 增大初始步长（15-20）

3. **参数设置不当**
   - ✅ 增加最大迭代次数
   - ✅ 降低相似度阈值
   - ✅ 尝试不同的优化策略

### Q2: 配准速度太慢如何优化？

**优化方法：**

1. **启用GPU加速**
   - 确保系统安装了CUDA
   - 检查GPU驱动是否最新
   - 在DRR生成方法中选择"GPU-Accelerated"

2. **调整参数**
   - 减少迭代次数（但可能影响精度）
   - 适当降低相似度阈值
   - 使用多分辨率策略

3. **硬件升级**
   - 使用更强大的GPU
   - 增加系统内存

### Q3: 配准结果如何评估？

**评估指标：**

1. **定量指标**
   - **相似度分数**：≥ 0.85为良好
   - **投影误差**：< 2mm为优秀
   - **目标配准误差（TRE）**：< 3mm为临床可接受

2. **定性检查**
   - 骨骼轮廓对齐
   - 关键解剖标志点匹配
   - 多个视角的一致性

3. **临床验证**
   - 与术中实际位置对比
   - 多次配准的重复性
   - 不同观察者的评估一致性

### Q4: 如何处理金属伪影？

**处理策略：**

1. **图像预处理**
   - 使用金属伪影校正算法
   - 调整窗宽窗位减少伪影影响

2. **配准参数调整**
   - 降低伪影区域的权重
   - 使用鲁棒的相似性度量

3. **数据选择**
   - 尽量使用术前CT数据
   - 避免包含大量金属植入物的区域

### Q5: 双视角配准失败单视角成功？

**可能原因：**

1. **视角质量不一致**
   - 检查两个视角的图像质量
   - 确认拍摄角度是否正交

2. **视角间冲突**
   - 两个视角的配准结果不一致
   - 尝试分别进行单视角配准
   - 检查C臂位置是否准确

3. **权重不平衡**
   - 调整AP和LAT视角的权重比例
   - 优先使用质量更好的视角

## 💡 最佳实践

### 数据采集建议

#### CT扫描
1. **扫描参数**
   - 层厚：0.5-1.0mm
   - 重建间隔：≤ 层厚
   - 视野：覆盖完整手术区域 + 周边10cm

2. **扫描时机**
   - 尽量接近手术日期
   - 避免在有严重金属植入物后扫描
   - 患者体位应接近手术体位

#### X光拍摄
1. **拍摄要求**
   - AP和LAT视角尽量正交（90度）
   - 图像清晰，无运动伪影
   - 包含足够的解剖参考

2. **拍摄技巧**
   - 固定C臂位置记录
   - 使用一致的射线参数
   - 避免过度曝光或欠曝光
