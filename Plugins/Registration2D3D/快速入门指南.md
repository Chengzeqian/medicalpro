# 2D-3D配准系统 - 快速入门指南

## 🚀 5分钟快速上手

### 第一步：启动系统
1. 运行 `medicalpro.exe`
2. 登录系统
3. 选择 **"手术导航系统"**
4. 点击 **"手术注册"** 标签页
5. 点击 **"2D-3D配准"** 按钮

### 第二步：加载数据（1-2分钟）

#### 方式1：使用测试数据（推荐新手）
```
1. 点击 [加载CT图像] → 选择测试数据目录中的CT文件夹
2. 点击 [加载AP视图] → 选择 test_ap.dcm
3. 点击 [加载LAT视图] → 选择 test_lat.dcm
```

#### 方式2：使用实际病例数据
```
1. 点击 [加载CT图像] → 浏览到患者CT数据
2. 点击 [加载AP视图] → 浏览到术中X光AP图像
3. 点击 [加载LAT视图] → 浏览到术中X光LAT图像
```

**数据加载成功标志：**
- ✅ AP视图窗口显示正位X光图像
- ✅ LAT视图窗口显示侧位X光图像  
- ✅ CT视图窗口显示3D重建或状态提示

### 第三步：设置参数（30秒）

**新手推荐配置（无需修改）：**
```
✓ 优化算法: CMA-ES（默认）
✓ 最大迭代次数: 500（默认）
✓ 初始步长: 10.0（默认）
✓ 相似度阈值: 0.85（默认）
✓ DRR生成方法: GPU-Accelerated（默认）
```

**如果想要快速测试：**
```
修改 "最大迭代次数" 为 300
（配准速度更快，但精度略低）
```

### 第四步：开始配准（2-5分钟）

1. 点击 **[开始配准]** 按钮
2. 观察进度条和状态信息：
   - 🔵 初始化 (0-5%)
   - 🟡 粗配准 (5-30%)
   - 🟠 精配准 (30-80%)
   - 🟢 优化收敛 (80-100%)

**配准过程中可以：**
- 查看实时日志输出
- 观察当前阶段和进度
- 如需中止，点击 [取消] 按钮

### 第五步：查看结果（1分钟）

配准完成后，在 **配准结果** 区域查看：

**关键指标：**
```
✅ 成功: 是
✅ 度量值: ≥ 0.85（良好）
✅ 执行时间: 2-5分钟（正常）
```

**视觉验证：**
- 在 **配准结果视图** 查看DRR叠加效果
- 检查骨骼轮廓是否对齐
- 确认关键解剖标志点匹配

### 第六步：保存结果（30秒）

1. 确认配准结果满意
2. 点击 **[保存结果]** 按钮
3. 选择保存位置
4. 输入文件名
5. 点击保存

## 🎯 成功配准的3个标志

### 1. 定量指标达标 ✅
```
相似度分数 ≥ 0.85
状态显示: "成功"或"已完成"
```

### 2. 视觉检查通过 ✅
```
DRR叠加图像中：
- 骨骼轮廓对齐良好
- 关键解剖结构重合
- 无明显错位或扭曲
```

### 3. 临床可用 ✅
```
配准结果与术中实际情况相符
多次配准结果一致性好
医生确认可用于手术导航
```

## 🛠️ 遇到问题？

### 问题1：加载数据失败
**解决方案：**
- 检查文件格式是否支持
- 确认文件路径无中文或特殊字符
- 尝试重新导出图像数据

### 问题2：配准速度很慢
**解决方案：**
- 确认已启用GPU加速
- 减少最大迭代次数到300
- 关闭其他占用GPU的程序

### 问题3：配准失败
**解决方案：**
- 检查X光图像质量
- 降低相似度阈值到0.80
- 增加初始步长到15.0
- 尝试生成DRR预览查看初始对齐

### 问题4：结果不准确
**解决方案：**
- 增加最大迭代次数到700-1000
- 提高相似度阈值到0.90
- 检查AP和LAT视角是否正交
- 验证CT和X光的解剖结构是否匹配

## 📊 性能基准参考

### 硬件配置与配准时间

| 硬件配置 | 配准时间 | 说明 |
|---------|---------|------|
| **推荐配置** | 2-3分钟 | GPU: RTX 3060+, CPU: i7+ |
| **最低配置** | 5-8分钟 | GPU: GTX 1060, CPU: i5 |
| **无GPU** | 15-30分钟 | 仅CPU计算（不推荐） |

### 数据大小影响

| CT层数 | X光分辨率 | 配准时间 |
|-------|----------|---------|
| 200-300层 | 1024×1024 | 2-3分钟 |
| 400-500层 | 1024×1024 | 3-4分钟 |
| 600+层 | 2048×2048 | 5-7分钟 |

## 💡 专业提示

### 提示1：数据准备
> 高质量的输入数据是成功配准的关键。建议使用层厚≤1mm的CT和高分辨率X光图像。

### 提示2：参数选择
> 首次使用默认参数即可。熟悉系统后，可根据病例特点调整参数优化配准效果。

### 提示3：结果验证
> 永远不要只依赖数值指标。必须通过视觉检查和临床验证确保配准结果可靠。

### 提示4：效率优化
> 提前准备好数据，设置参数模板，可以将单次配准时间缩短到3分钟以内。
